# 楊梅高中分機一覽表 - 互動式校園通訊資訊網

依據 **桃園市立楊梅高級中學語音電話分機一覽表（版本：115/09/07，編製：總務處）** 打造的現代化、視覺化互動通訊資訊網。

---

## 🌟 系統亮點與特色

### 1. 📱 全平台與跨裝置自適應 (Responsive Design)
- 完美支援 **智慧型手機**、**平板電腦** 與 **桌上型電腦**。
- 手機端單欄觸控友善大卡片、平板雙欄、電腦三至四欄響應式佈局。

### 2. 🔍 即時模糊檢索與多元分類瀏覽
- **即時智慧搜尋**：支援輸入處室、姓名（如：李主任、鍾校長）、分機號碼（如：1201）、職稱、專科教室、建築大樓或直撥電話，鍵入即時過濾並高亮匹配字詞。
- **色彩分類膠囊**：提供 11 大類處室膠囊標籤（校長室與協力、教務處、學務處與校安、總務處、輔導室、圖書館、實習處、人事/會計/員生社、導師與專任、專科教室與實驗室、御風樓生科大樓），一鍵切換查看。
- **雙檢視模式**：支援「彩色卡片網格檢視」與「條列式詳細表格檢視」。

### 3. 🎨 明亮活潑視覺化與無障礙大字體設計
- 採用充滿校園朝氣的陽光藍天與溫暖晨光漸層色調，各處室以專屬主題色彩（琥珀金、湛藍、活力橘、翡翠綠、紫羅蘭等）與精美 SVG 徽章清晰標示。
- **字體大小貼心控制**：提供「正常 (100%)」、「大字 (115%)」、「特大 (130%)」三段切換，分機號碼採用超大粗體（28px～36px），讓師長與各年齡層都能輕鬆閱讀。
- 動態流光特效、懸浮卡片浮動、點擊回饋與滑入動畫。

### 4. 🔊 豐富互動性與 Web Audio API 原生音效
- **真實 DTMF 雙音多頻電話撥號盤（📞 撥號盤）**：模擬真實電話按鍵，按鍵 1~9, 0, *, # 發出標準國際電信雙頻音效，輸入 4 位數分機自動匹配處室與人員，可一鍵直撥！
- **一鍵複製分機**：點擊分機大字號碼立即複製到剪貼簿，並伴隨清脆的「Ding-Dong」悅耳雙音與浮動 Toast 提示通知。
- **一鍵撥號直撥**：在行動裝置上點擊撥號按鈕，直接啟動手機通話轉接分機（`tel:034789618,分機`）。
- **⭐ 常用分機星號收藏**：可點擊星號收藏常聯繫的分機，自動保存於本機儲存空間，並提供快速過濾。
- **🔊 真人語音朗讀分機**：內建 Web Speech 繁體中文語音合成，點擊卡片喇叭即以清晰中文朗讀處室、人員與分機號碼。
- **音效切換**：頂部配備「音效開關」，可自由切換靜音與開啟。

### 5. 🖨️ 友善列印功能
- 內建專屬 `@media print` 列印樣式，一鍵列印整齊漂亮的 A4 分機清冊，適合張貼於辦公桌前。

---

## 📂 檔案目錄結構

- `index.html`：網頁主結構與語意化排版
- `style.css`：全響應式 CSS 樣式、色彩主題與動畫
- `data.js`：完整楊梅高中分機資料庫（共收錄 19 個處室/建築、全數 136+ 筆分機及專線傳真）
- `audio.js`：Web Audio API 音效引擎（含 DTMF 撥號音、和弦提示音與語音朗讀）
- `app.js`：檢索過濾、收藏儲存、虛擬撥號盤與互動控制邏輯

---

## 🚀 使用方式

直接於任何現代瀏覽器（Google Chrome, Microsoft Edge, Safari, Firefox 等）中雙擊打開 `index.html` 即可立即使用，**完全無須安裝外部伺服器或依賴任何外網套件**，100% 支援離線瀏覽！
